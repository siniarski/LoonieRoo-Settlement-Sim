- **2026-11-09, the self-test made reliable** (branch claude/selftest-hardening-072cc6). Brief (a side session): the flaky "The mouse turns you" step, and fresh worktrees hanging on unimported models. **The flake's cause:** Godot's input accumulation (`Input.UseAccumulatedInput`, on by default) merges mouse motions queued in the same frame into one event, keeping the first event's device id. A real mouse movement in the frame of the test's quarter turn was folded into the test's event (device 7777), so `DropForeignMouse` let it through and the yaw came out 0.01-0.02 off; 0.02 crosses the aim's 1.4-degree snap and the step failed. Reproduced both ways: a device-0 motion of 8 px parsed right after the test's gives exactly the reported "yaw 0.02, aim 64,2"; and with the real mouse moved by `SendInput` throughout a run (raw relative steps of 3 px every few ms), the unfixed step read yaw 0.01, 0.01, -0.01 in three runs. **Fix:** the self-test turns accumulation off before its first step (one event each, so the device filter is exact), and the step now injects that stray device-0 motion itself, so the guard is checked every run. With the fix, 12 runs in a row with the real mouse moving throughout: all green, yaw 0.00 every time. (One unfixed run with the mouse moving also failed "A zombie that sees you snarls"; not seen in the 12 fixed runs.) **Fresh worktrees:** `_Ready` threw on `items.glb` (GD.Load gives null for an unimported model) so the test never started and check.sh sat out its 180 s. Now `./check.sh --all` always runs `--headless --path godot --import` first (8.8 s fresh, 2.6 s with nothing new; it also picks up models added by a merge). Run by hand, `--selftest` first checks every `res://**/*.import` has its imported file (any of path / path.s3tc / path.etc2) and if not prints "FAIL Assets imported (N not imported, first ...)" and quits with 1 in 1.6 s, before building anything (Game.cs: one line in _Ready). A step that throws now fails the run and quits instead of hanging; check.sh says when the self-test timed out. **Checked:** `rm -rf godot/.godot` then `./check.sh --all`: green in 43 s, 674 sim tests, 40 self-test checks, no manual import.
