  - **Bugs found (all in the C#):** road curves are fractional and Point truncated them (RoadPoint in the TS, PointD in the C#), so every world 128 and up differed; an empty list's [0] read as 0, not undefined (a node linked to itself); Mood's base durations read after setDayScale (thoughts doubled twice on long-day worlds); int * int overflowed 32 bits (a swing's arc test): every multiplication is now in doubles, as JS; double-to-int overloads truncated distances (Worldplan.dist, Herds.direction). And toFixed now rounds the double's exact value as JS does (0.85 -> "0.8"). Found by making Js.I throw on fractions and by bisecting harness runs tick by tick (LOG= / LOG_AT= in the colony and solo harnesses dump states to compare).
  - **Speed, C# against V8 (bench, stress):** level on small worlds, faster on the 10-day run (0.08 against 0.11 ms a tick); about half V8's speed on 512 worlds (190-250 ticks/s against 390-490; 40 needed at 4x); colonist-heavy 128 rows 2-3x slower. Saving a 512 world is the weak spot: ~1 s in C# against ~10 ms (Savefile.cs on JSON nodes). Worth a look before big worlds, not blocking.
