- **2026-11-07, A* benchmarks (branch godot-astar).** Player: "And pathfinding benchmarks?" The same A* written in TypeScript, GDScript, C# and C++, plus Godot's AStarGrid2D, over the same start and goal pairs (harness godotastar writes them), tiles only. All found the same total length. 128 world, 200 paths / 1024 world, 60 long paths: TypeScript 12.6 / 341 ms; the game's findPath 17.1 / 975 ms; C# Debug 15.6 / 471 ms, optimised 7.8 / 190 ms; C++ plugin 3.8 / 116 ms; AStarGrid2D 2.8 / 458 ms; GDScript 266 / 8,231 ms. So C++ is about 3x TypeScript, optimised C# under 2x, GDScript 20-24x slower; the game's own pathfinder costs up to 3x a plain A* for edges, doors and caches (worth a look at scale).
