- **2026-11-11, the code's structure.** The player asked for a quality pass (separation of concerns) and a layout to review in person. Nothing in the sim's behaviour changed: files moved, one class was split into parts, and the game's direct writes to the state went behind sim functions.
  - **What was wrong.** `cs/Sim/Systems` held 125 files in one folder and `cs/Sim` 21 more, with nothing to say which belonged together. `godot/Game.cs` was 1,050 lines of five jobs (what the game is made of, the command line, sessions and saves, input, screenshots). Labs and benches (20 files, 10 scenes) sat among the runtime code in `Characters/` and `World3D/`. Rule 5 (the game only reads state) had exceptions: sixteen debug flags and two lineups wrote state fields or called sim mutators from the game, and the dawn autosave reset `state.commandLog` from `_Process`.
  - **Decided.**
    - **The sim by area.** `cs/Sim/<Area>/<Name>.cs` in sixteen folders (Js, State, Core, Save, Grid, Debug, Movement, Worldgen, World, Combat, Dead, Items, Colony, Survivors, You, Others), moved with `git mv` so history follows. One namespace still: folders are for finding things. docs/modules.md is rewritten around the folders.
    - **Tests stay flat.** `XTest.cs` is X's; the files ported from TypeScript are grab-bags (BalanceTest opens with trees, PeopleTest with books), so folders would mislead. docs/modules.md lists what the odd names cover.
    - **`Staging` (cs/Sim/Debug).** Every hand-set debug scene is a sim function now: `day`, `hour`, `clock`, `weather`, `snow`, `mainsOff`, `place`, `arm`, `giveFlashlight`, `flipSwitch`, `car`, `fire`, `burn`, `stove`, `heater`, `itemLineup`, `furnitureLineup`. Still not commands and not logged. `Savefile.restartLog` is the dawn reset. The lineups moved out of `World3D/Items.cs` and `Furniture.cs` (a renderer was spawning sim things); `ItemModels.ShowAs` keeps only the forced model variants. `--lineup` has the flashlight too.
    - **The game class in parts** (`godot/App`): Game.cs (`BuildViews`, the frame, `_Draw`), GameArgs.cs (every flag documented once, at its top; `WorldFromArgs`, `SkyArgs`, `SceneArgs`, `ViewArgs` in the order that matters), GameSession.cs, GameInput.cs (with the light keys; GameLights.cs is gone), GameShots.cs, GameText.cs. `godot/SelfTest/`, `godot/Labs/` (scene paths, docs and art scripts updated: `res://Labs/Lab.tscn`). main.tscn points at `res://App/Game.cs`.
    - **`ArchitectureTest`.** Three tests over the source text: the sim has no Godot, wall clock or unseeded randomness; every sim file is in an area folder, opens with a comment and is in docs/modules.md; the game (not SelfTest or Labs) never assigns a state field, changes a state list or calls a spawning function. Tripwires, not proofs (comments stripped, regexes).
    - **README.md** at the root, for a person: the shape, a reading order, the layout, the two things that look odd (JavaScript semantics, one namespace of static classes).
  - **Left.** The long single-concern files (docs/open-work.md "Code structure"): `Commands.execute` most of all. Branches `claude/*` (21, all merged) were left in place when the sessions were archived and their worktrees removed. Check green (882 tests, self-test 96).
